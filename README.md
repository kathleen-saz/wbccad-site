# WBCcad marketing site

A new Portuguese-language marketing site concept for WBCcad, built with Next.js and designed for Vercel.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run typecheck
npm run build
```

## Research basis

The positioning and product content were researched from WBCcad's official public sites:

- [WBCCAD overview (Portuguese)](https://wbccad.com.br/visao-geral.html)
- [Modules (Portuguese)](https://wbccad.com.br/modulos.html)
- [Features and benefits](https://wbccad.com/features)
- [About Workbench](https://wbccad.com/about-us)

The public brand uses **WBCcad** and currently operates at `wbccad.com` / `wbccad.com.br` (double “c”).
